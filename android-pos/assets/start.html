Setu kahan se chalana hai?

Restaurant ke WiFi par

Waiter, cashier, kitchen ke liye. Counter PC chalu ho aur phone usi WiFi par ho. Counter PC ka address Setu → Settings (G) → "Phone / Tablet Connect" mein likha hota hai (jaise 192.168.1.6).

Internet se (Hotel Setu Cloud)

Owner ke liye, kahin se bhi. Hotel Code aur owner password / PIN chahiye.

Ye choice yaad rahegi. Badalni ho to Setu mein Back dabate rahiye, ye screen wapas aa jayegi.
