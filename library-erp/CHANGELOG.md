# Library ERP — Version history

Har naye update par version badhta hai. ERP mein version neeche side menu aur License (K) screen par dikhta hai.

| Version | Naam | Kya aaya |
|---|---|---|
| **1.5.0** | Session Wise | Upar patti se session badlna; fee, due, receipt, kharcha aur reports session-wise; pichhle session ki due fee "Switch & collect" se |
| 1.4.0 | Countdown | License ka live countdown (aakhri 48 ghante); keygen mein minute / ghante wali key; library naam par click se Dashboard |
| 1.3.0 | Expense | Session master, Expense Heads, Expense Entry, Income vs Expense (Profit / Loss), Expense Report, dropdown menu (M / T / R / U) |
| 1.2.0 | Dashboard | Charts wala Dashboard, poora ERP English mein, galat fee delete karke students shift karna |
| 1.1.0 | Setup | Setup installer (Desktop icon), bina kaali window, mahine tick wali fee, Student Record, In / Out time, due reminder popup, Excel import format |
| 1.0.0 | First release | Students, Fee Master, receipts (58 / 80 mm, A4 / A5 / A6), WhatsApp, attendance, Day Book, backup (email), activation key |
